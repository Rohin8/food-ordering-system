# Food Ordering System

A PHP and MySQL food ordering system that can run locally using XAMPP.

## Project files

Download `fos-project.zip` from this repository and extract it into
`C:\xampp\htdocs\fos`.

## Run locally

1. Start Apache and MySQL in XAMPP.
2. Import `fosdb.sql` into a MySQL database named `fosdb` using phpMyAdmin.
3. Open http://localhost/fos/ in your browser.
